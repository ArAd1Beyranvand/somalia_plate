# somalia_plate

Somalia's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the bilingual `SOM` / `الصومال` plate with the coat of arms over a two-letter, four-digit serial, black on white, with its theme, alphabets and an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:somalia_plate/somalia_plate.dart';

PlateCanvas(
  spec: SomaliaPlates.standard,
  theme: SomaliaThemes.standard,
  validator: const SomaliaPlateValidator(),
  autoValidate: true,
);
```
